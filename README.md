# 🛒 Multi-Vendor E-Commerce Platform

A full-stack MERN-based e-commerce platform where multiple vendors can manage their products and customers can browse and purchase products through a single marketplace.

## 🚀 Features

- **User Authentication** – Secure login and registration.
- **Admin Dashboard** – Manage users, sellers, products, and platform activities.
- **Seller Dashboard** – Manage individual stores and products.
- **Product Management** – Add, update, and delete products.
- **Shopping Cart** – Add and manage products in the cart.
- **Order Management** – Place and track customer orders.
- **Coupon & Discount Management** – Apply coupon codes and get discounts.
- **Multi-Vendor Support** – Multiple sellers can sell products on one platform.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT

## ⚙️ Getting Started

Follow these instructions to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/krishankumargupta111/multivendor.git
cd multivendor
```

### 2. Start the Backend

```bash
cd backend
npm install
npm run dev
```

### 3. Start the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```
